      🧬 Technology

      How Our AI Works

      Convolutional Neural Network

      4-block deep CNN with batch normalization, dropout regularization, and data augmentation. Learns spatial features directly from dermatoscopic images.

      128×128 input 256-dim features 7 output classes

      Support Vector Machine

      RBF-kernel SVM trained on CNN-extracted features. Provides complementary classification with class-weighted training for imbalanced datasets.

      RBF kernel StandardScaler Probability calibration

      Ensemble Prediction

      Weighted ensemble combining CNN (60%) and SVM (40%) predictions for superior accuracy. Severity and stage determination from clinical mapping rules.

      60% CNN weight 40% SVM weight 4 severity levels

      Training Dataset

      Trained on 1000+ dermatoscopic images from 7 disease classes with extensive data augmentation including rotation, flipping, zoom, and brightness variation.

      1050+ images 7 classes 80/20 train-val split
